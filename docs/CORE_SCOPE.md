# Core scope

SEMA Core owns only cross-application mechanisms:

- Identity and identifier reservations
- Commands, executions, results, events, and audit records
- Capability registration, local discovery, authorization, and resolution contracts

SEMA Core does not own Foundation entities, application workflows, graphics tools, item categories, files, bundles, listings, costing, marketplace logic, or user-interface code.

Foundation and application services use Core through its stable API.
